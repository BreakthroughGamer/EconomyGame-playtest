# Economy Game: playtest

An early build of a logistics and economy game: log the forests, run trucks, saw lumber, and grow the towns.

**Play it here: https://breakthroughgamer.github.io/EconomyGame-playtest/**

It runs in the browser (desktop Chrome, Edge or Firefox work best). Every build is a work in progress, and things will break.

## Reporting bugs and ideas

Found a bug, or have an idea? [Open an issue](https://github.com/BreakthroughGamer/EconomyGame-playtest/issues/new/choose). The **Report a bug** link in the game's menu (Esc) fills in which build you're on.

Screenshots help a lot: paste them straight into the issue.

This repo holds only the built game; the source is private.
